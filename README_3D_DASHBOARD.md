# IoT 3D 设备管理平台

## 新功能特性

### 🎯 3D 模型展示
- 使用 Three.js 渲染 3D 设备模型
- 支持 GLB/GLTF 格式的 3D 模型
- 实时显示设备状态和动画效果

### 🎮 交互功能
- **点击模型**: 点击任意设备模型查看详细信息
- **相机控制**: 支持鼠标拖拽旋转、缩放视角
- **设备控制**: 直接在 3D 界面中控制设备状态

### 🌪️ 风扇设备动画
- **风扇旋转**: 根据档位速度实时旋转
- **摇头动画**: 开启摇头功能时模型会左右摆动
- **状态同步**: 3D 动画与后端数据实时同步

### 📱 响应式设计
- 适配桌面和移动设备
- 现代化的毛玻璃效果界面
- 流畅的动画过渡效果

## 技术栈

- **Vue 3** - 前端框架
- **Three.js** - 3D 图形渲染
- **Element Plus** - UI 组件库
- **Vite** - 构建工具

## 设备数据格式

```javascript
{
  id: 1,
  device_id: 'fan_001',
  name: '客厅风扇',
  device_type: 'electric_fan',
  status: 'online',           // online/offline
  fan_speed: 3,              // 0-3 档位
  oscillation: true,         // 是否摇头
  temperature: 25,           // 温度
  location: '客厅'
}
```

## 使用方法

1. 启动开发服务器: `npm run dev`
2. 在浏览器中访问应用
3. 点击 3D 场景中的设备模型
4. 在详情面板中控制设备状态
5. 观察 3D 模型动画变化

## 模型要求

- 支持 GLB/GLTF 格式
- 建议模型包含以下命名对象:
  - `fan_blades` 或 `blades` - 风扇叶片
  - `fan_base` 或 `base` - 风扇底座
- 模型文件放置在 `public/models/` 目录
- **自动备选方案**: 如果GLB模型加载失败，系统会自动创建简单的几何体风扇模型
- **智能缩放**: 模型会自动缩放到合适的大小
- **自动着色**: 系统会为模型的不同部分自动分配颜色

## 扩展功能
